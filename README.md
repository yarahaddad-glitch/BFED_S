project description:
  Our project proposes an automated robotic meal preparation and distribution system for a prison environment. 
  Colour-coded trays are used to represent different dietary requirements, such as vegetarian meals. 
  An RGB camera mounted to the first robot identifies the tray colour and determines the required meal. 
  The robot then transfers the tray between preparation stations, where two additional robots pick and place the appropriate food components into the tray. 
  Once completed, the tray is returned to the first robot for distribution. A fourth robot transports completed meals to designated isolation areas. 
  The system demonstrates coordinated robot manipulation, RGB sensing, pick-and-place, safe operation and user interaction within a shared workcell.
